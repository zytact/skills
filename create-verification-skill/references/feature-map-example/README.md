# Feature map

One file per user-facing feature of Notely, a notes web app. Each says how a user reaches the feature, how to drive it, and what proves it works.

| Feature | File | Entry points |
| --- | --- | --- |
| Search | [search.md](search.md) | Header search box, `/` shortcut, `/search?q=` URL |
| Sharing | `sharing.md` | Share button on a note, `/s/<token>` public link |
| Import | `import.md` | Settings, drag a `.md` file onto the note list |

A proof covers every entry point its feature lists.
