# Application answers

Facts for job application forms. The job-apply skill reads this before every run and appends new answers the user gives it. Keep it out of any git repository.

## Contact
- Phone: in the env var `APPLICANT_PHONE` (country code <code>)
- Email, LinkedIn, GitHub, portfolio: `basics.contacts` in resume.yaml
- Current city: <city, state, country>

## Education
- <degree>, <university>, graduating <month year>
- CGPA: <score> / <scale> as of semester <n>. Say "<how to write it where text fits>".

## Availability
- Start date: <date or "immediately">
- Hours: <hours a week, and when>
- Relocation: <yes or no>
- <whether the internship is college-mandated>

## Pay
- Expected stipend: <minimum a month>. A single number field gets <amount and currency>.

## Work authorization
- <citizenship, where they may work, whether they need sponsorship>

## Personal
- Age: <age>
- Gender: <gender>
- Nationality: <nationality>
- Ethnicity: <ethnicity, and which option to pick when the form's list lacks it>
- Veteran: <yes or no>
